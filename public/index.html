                    Setup

                    Each source is optional. Connect what you use; the rest shows as "not connected". Keys live as Worker secrets, never in the page or the repo.

                    1. Deploy and set a password

                      Run these from the repo folder. The password needs 16 or more characters.

                      npm install
npx wrangler deploy --domain analytics.example.com
npx wrangler secret put DASHBOARD_PASSWORD

                      Every later setting can go in one file: copy .dev.vars.example to .dev.vars, fill it in, then run npx wrangler secret bulk .dev.vars.

                    2. Say what the site is for

                      SITE_NAME, SITE_URL (the address people visit), TIMEZONE (for example America/New_York), and SITE_GOAL: one sentence on what a good visit ends with. The AI read judges everything against it.

                    3. Umami (visits, paths, clicks)

                      1. In Umami, open Settings, then API keys, then Create key. Copy it into UMAMI_API_KEY.
                      2. Open Settings, then Websites, then Edit on your site. Copy the Website ID into UMAMI_WEBSITE_ID.
                      3. Self-hosted only: set UMAMI_API_URL to https://your-umami-host/api.

                    4. Google Search Console (Google searches)

                      1. In Google Cloud Console, create a project (or pick one), open APIs and Services, and enable the Google Search Console API.
                      2. Open IAM and Admin, then Service accounts, then Create service account. No roles needed. On the new account, open Keys, Add key, JSON. A file downloads.
                      3. In Search Console, open Settings, then Users and permissions, then Add user. Paste the service account's email (the client_email in the file) with Restricted permission.
                      4. Upload the file and name the property, then delete the file: 
                        npx wrangler secret put GSC_SERVICE_ACCOUNT < key.json
npx wrangler secret put GSC_SITE
                        GSC_SITE is sc-domain:example.com for a domain property, or the full URL with the trailing slash for a URL-prefix property.

                    5. Bing Webmaster Tools (Bing searches)

                      1. If your site is not in Bing yet, add it there; "Import from Google Search Console" does it in one step.
                      2. Open Settings (the gear), then API access, then API key, and generate one. Copy it into BING_API_KEY.
                      3. Set BING_SITE to the site exactly as Bing lists it, for example https://www.example.com/.

                    6. Cloudflare Web Analytics (speed)

                      1. Turn on Web Analytics for the site in Cloudflare if it is off.
                      2. In Cloudflare, open My Profile, then API Tokens, then Create Token, then Custom token. Give it one permission: Account, Account Analytics, Read. Copy it into CF_API_TOKEN.
                      3. Copy your Account ID (Workers and Pages overview, right-hand column) into CF_ACCOUNT_ID. The Worker filters to the hostname in SITE_URL.

                    7. The AI read (Claude)

                      Create a key at console.anthropic.com under API keys and put it in ANTHROPIC_API_KEY. One read of a month of data costs a few cents; each read is kept for the day. AI_MODEL overrides the default model.
